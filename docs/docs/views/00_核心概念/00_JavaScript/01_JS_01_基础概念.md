
## 标识符 
标识符 是由字母 数字 下划线(_)组成，不能数字开头 不能是关键字保留字，严格区分大小写，用来命名变量的符号。
## 常量 
- 常量是用const声明的变量。常量不能修改，引用类型的变量不变就不算修改。

## Symbol 
Symbol是es6新增的基础数据类型, 可以用来创建绝对唯一的标识符，不需要关注值本身是什么
Symbol() 不会被遍历 for of forin Object.keys中拿不到symbol()

应用场景，比如 
1. vue模版中的key 可以传Symbol()
2. provide 的key值
3. 常量
```js
export const KEY = Symbol('我是一个key值'); // 参数是描述信息 类似注释
```

## 循环 递归 遍历 迭代的区别 
比较相似但侧重点不同，

遍历侧重访问数据结构中的每一个元素。只是看一下所有元素。
迭代侧重于按顺序从数据结构中一个个主动取出来。按某种顺序取出来所有元素。
循环是侧重于 重复执行某一段代码。
递归是 函数自己调用自己。没有结束条件就会导致栈溢出


## const/let/var区别 
1. const和let的唯一区别是 const必须赋值且不能修改。
2. let 和 var 的区别是 
3. let是块级作用域  var是函数作用域
4. let不能在声明前访问 会报错暂时性死区  var可以在声明前访问 var有变量提升 
5. 一般是 无脑const 修改用let 不用var

## 深浅拷贝 
浅拷贝：只复制对象的第一层属性。如果属性值是基本类型，拷贝的是值；如果属性值是引用类型（对象、数组），则拷贝的是内存地址。因此，新旧对象会共享同一个嵌套对象，修改一方会影响另一方。

深拷贝：递归复制对象的所有层级。它会创建一个完全独立的对象，在堆内存中开辟新空间。新旧对象完全隔离，修改任意一方都不会影响另一方。

如何实现浅拷贝： 展开运算符...  Object.assign() 数组的slice和concat()
如何实现深拷贝:
- JSON.parse(JSON.stringify(obj)) 缺点是 不支持函数和循环引用
- lodash.cloneDeep() 好处是 支持函数、循环引用 
- window.structuredClone({a: {a:1}})
