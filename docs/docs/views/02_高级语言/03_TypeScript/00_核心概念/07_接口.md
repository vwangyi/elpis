
## 接口

ts中的interface 就是 约束 类 对象 函数 的接口 这个接口有约束的意思 比如都是 type-C 都是 USB

## interface约束对象
```ts
interface User {
  name: string;
  age: number;
  sayHello: () => void;
  sayHello1(): void,
}

const u: User = {
  name: 'hello',
  age: 12,
  sayHello() {

  },
  sayHello1() { }
}

console.log(u)
// 约束对象 优先用 interface 而不是type类型别名  个人习惯而已 interface高级一点
```

## interface约束函数
```ts
interface Condi {
  (n: number): boolean
}
function sum(nums: number[], callback: Condi) {
  let s = 0;
  nums.forEach(n => {
    if (callback(n)) {
      s += n;
    }
  })
  return s;
}

const result = sum([24, 4, 64, 6], (n) => n % 2 === 0)
console.log(result);

interface A {
  T1: string
}
interface B {
  T2: string
}

interface C extends A, B { // interface可以多继承 
  T3: boolean
}
const u: C = {
  T1: '',
  T2: '',
  T3: true
}
console.log(u)


// interface 中 不能覆盖 父接口的成员 

```

## readonly 修饰符
```ts
// 表示 number[] 是只读的
const arr: readonly number[] = [1, 2, 3]; // arr.push 等会影响原数组的方法 都不可用了
const arr: ReadonlyArray<number> = [1, 2, 3]; // arr.push 等会影响原数组的方法 都不可用了


interface User {
    readonly id: string
    name: string
    age: number
}
let u: User = {
    id: '123',
    name: 'asdf',
    age: 12
}
// u.id = 'asfda' // 报错 不能修改


type User1 = {
    readonly id: string
    name: string
    age: number
    readonly arr: string[]
    readonly arr1: readonly string[]
}
User1.arr = [] // 报错  
User1.arr.push('') // 可以成功

User1.arr1 = [] // 报错
User1.arr1.push('') // 报错
```
