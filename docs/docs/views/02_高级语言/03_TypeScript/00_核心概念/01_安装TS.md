## 安装TS环境
```sh
pnpm i typescript -g # 得到 tsc命令  通过 tsc ./index.ts 
```

## ts配置文件 tsconfig.json 
- 通过 tsc --init 生成 tsconfig.json 
```json
{
    // 编译选项
    "compilerOptions": {
        "target": "es2016", // 把ts编译为js时 使用什么es版本 默认是es3
        "module": "commonjs", // 使用什么模块化标准  commonjs 和 es6
        "lib": ["es2016", "dom"], // 采用什么编译环境   如果需要node 额外安装@types/node 的node环境
        "outDir": "./dist",  // 编译的输出目录
        "strictNullChecks": true, // 开启严格的空值检查 null和undefined 就不能赋值给任意类型 只能赋值给自己。
        "removeComments": true, // 编译结果移除注释
        "noImplicitUseStrict": true, // 是否移除 js的严格模式 use strict
        "esModuleInterop": true, // 可以用 import fs from 'fs'
        "noEmitOnError": true, // ts发生语法错误时不生成编译结果
        "moduleResolution": "node", // 模块解析模式 node和classic classic是旧的  一般用node 
        "strictPropertyInintialization": true,  // 封装类的属性方法时 属性必须初始化 不初始化值为undefined 是不行的 （属性的初始化检查）
        "noImplicitAny": true, // 开启对隐式any类型的检查 当ts自动推导为any的隐式any是否类型正确 ，比如  用中括号访问不存在的成员也会报错，开启这个配置也就意味着 ts会更加严格 ，如果你的ts很强就开启 不强就不开启

    },
    // include 表示只需要编译src下的ts文件  files和include一样 files是具体的文件 include是文件夹
    "include": ["./src"],
    "files": ["./src/index.ts"],

}


```
## @types
- @types是 ts官方的类型库 包含了很多对js代码的类型描述。
- 比如 jquery是纯js写的 也可以在ts中使用jquery， 安装ts官方提供的 @types/jquery
- @types/node   pnpm i -D @types/node
