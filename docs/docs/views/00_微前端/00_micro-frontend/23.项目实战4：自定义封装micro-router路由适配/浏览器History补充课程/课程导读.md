# 浏览器 History 补充课程

这套内容用来快速掌握浏览器 History 的核心知识。全部案例只使用原生 HTML、CSS 和 JavaScript，不依赖任何框架或构建工具。

## 学完能解决什么问题

你应该能够直接回答：

- `pushState` 和 `replaceState` 有什么区别？
- 为什么它们不会自动触发 `popstate`？
- `history.state` 保存在哪里？
- 浏览器回退时，`event.state` 属于哪个页面？
- 为什么 `replaceState` 会覆盖原来的 state？

## 学习顺序

| 课时 | 内容                      | 建议时间 |
| ---- | ------------------------- | -------: |
| 1    | 浏览器地址与历史栈        |  10 分钟 |
| 2    | pushState 与 replaceState |  15 分钟 |
| 3    | popstate 与前进后退       |  15 分钟 |
| 4    | history.state             |  15 分钟 |

## 启动案例

History API 对页面来源有安全限制，不建议直接双击 HTML 文件。请先在 VS Code 扩展商店安装 **Live Server**：

1. 使用 VS Code 打开课程目录；
2. 在 `案例/index.html` 上点击鼠标右键；
3. 选择 **Open with Live Server**；
4. 从案例入口进入实验页面。

如果右键菜单里没有这个选项，请确认 Live Server 扩展已经安装并启用。

## 最重要的学习方式

每次点击按钮前先预测：

```text
URL 会不会变化？
历史记录会不会增加？
history.state 会变成什么？
会不会触发 popstate？
```

预测之后再操作，比直接记结论更容易真正掌握。
